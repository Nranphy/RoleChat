# UI验收清单

文件名沿用早期预览阶段；应用已没有界面预览/展览Tab。当前是实际OPFS与Agent运行程序，不能再用演示数据描述生产行为。代码位于lib/presentation，测试按test/presentation组织。

## 页面

- 聊天、角色、设置三个入口，宽屏导航/双栏，窄屏返回与底部导航。
- 空会话仅显示“暂无对话”；新建角色得到空私聊，预设群也无初始假消息。
- 角色卡仅头像与名称；点击进入资料，删除独立按钮。角色/设置共用ContentPage。
- 角色与群资料共用ProfileDialogFrame，固定左对齐Tab，文档说明行和按钮尺寸一致。

## 交互

- Enter发送，Shift+Enter换行；输入文本垂直位置正确。
- 长文本气泡实际高度正确，同人连续消息合并头像/名称；用户和角色菜单位置分别在气泡外左/右侧。
- 消息菜单仅行hover时显示；选中会话不叠加局部hover或黑色点击层，过渡自然。
- 搜索含发送者、按时间倒序；搜索结果及两种引用均可定位消息，姓名保留角色色。
- API/模型联动选择，模型只来自所选API；检测显示真实成功/失败，修改选择使旧结果失效。
- API内多个模型在同一弹窗编辑；重复模型ID校验，改名同步引用，删除引用模型前确认。
- 头像可裁剪、刷新后保留；有图不闪烁，无图才用首字底色。名称下划线适应浅深主题。
- 样例、行程空态/添加/删除、统一字段高度；时区下拉、数字时间输入、文档/行程自动更新锁。
- 明暗默认跟随系统；主题切换覆盖菜单和弹窗。无装饰性标语、简介、已读、免打扰或程序内参考来源说明。

## 数据与异常

初始化仅以标记控制；删除预设后保留标记刷新不补回。清除标记再刷新补缺，重复不生成副本。归档、恢复、永久删除、清理范围和ZIP Key勾选均有明确提示。

保存失败保持编辑窗口；关闭检测弹窗后异步返回不修改已销毁组件。新消息导致旧模型返回失效时，不公开旧内容；UI输入中外观不承担调度信号。

自动测试覆盖主要交互、浅深主题与窄宽屏。真实浏览器仍需验证OPFS恢复、文件上传下载、长时间后台及供应商工具协议；不以mock结果替代实机验收。
