# 最终方案与实现规则

本文件汇总当前用户要求及授权默认；源码层次见17-modular-architecture，数据格式见04-data，运行交接见14-handoff。应用已实现核心流程，验证边界与未完成扩展单独列明。

## 范围与配置

Flutter Web单用户角色扮演，直接请求已有OpenAI兼容API，不含Matrix、登录、Android或独立后端。业务数据在OPFS，主题在浏览器偏好；模型Key独立auth.json。

每个API包含多个模型，模型ID在同API下唯一，参数独立。角色选择API/模型；更名联动引用，删除被使用模型前确认，确认后清空选择。新角色建空私聊；群聊有background.md和多角色成员。

角色包含identity.md、soul.md、memory.md、样例、行程及运行设置。identity仅用户改，soul/记忆/行程可自主更新并受用户锁控制。记忆跨该角色会话共用；历史权限按当前成员关系，刚加入可读早期历史。

## 激活默认

| 参数 | 规则 |
| --- | --- |
| 周期 | 默认5–30秒均匀随机，角色可配置 |
| 常规延迟 | 0–5秒均匀随机 |
| 行程切换 | p>0保证一次处理，延迟U[5(1-p),5+55(1-p)]秒，p按0–1 |
| 默认活动 | 无命中为自由活动，概率默认50%，角色可设0–100%及小数 |
| @ | 未查看的@固定倍率2，不累计，概率0不能唤醒 |
| 衰减 | d=max(0.05,2^(-max(0,n-6)/4))；最终min(1,p×@倍率)×d |
| 恢复 | 用户发言清空连续AI尾部；实际行程时段切换恢复角色会话基线，仅改文案不恢复 |

只靠周期与行程切换激活，不由新消息直接激活。规则支持每天、指定星期、每年月日、指定日期及日期范围，采用角色时区，匹配取最新修改顺序；时间左闭右开、跨午夜按开始日。

ActivationScheduler仅接收快照及请求；RoleplayActivationPolicy是可注入应用策略。每角色每目标最多一项等待，保留已排时间；同角色串行、不同角色并行。当前已在处理的会话不因行程切换再排一次。概率0清等待，不停止处理中任务。

## 三态与处理会话

暂停等待检查；激活包含随机延迟、角色队列和模型额度等待；处理中包含上下文、模型和工具。初始化成功后自动开始，后台按偏好与浏览器执行能力推进，不补跑每次错过的检查。

新消息进入当前会话时，在途HTTP自然结束，旧未执行返回失效，更新上下文后继续；已执行assistant/tool过程保留，不从空过程重跑。角色自己的发送不使自己重启；其他会话消息不抢占当前任务。

AgentExecution累计本次处理所有模型请求轮数，包括旧代次请求；重建不重置预算。工具调用ID重复复用原回执，参数冲突报错；不按正文过滤独立发送。finish后不执行同批剩余工具。

每次副作用核对epoch、角色/会话存在性、归档/成员关系、API/模型绑定和当前上下文；文档另外检查哈希和锁。开始推进游标，失败不回退，提示某角色试图发消息但失败。

## 上下文与工具

固定系统提示 → 固定tools参数 → 规范化共享历史 → 当前角色/文档/背景/时间/活动 → 已执行工具过程。previous_view_sequence与check_kind区分新消息和自主查看历史。tools字段的服务端实际排序由模型提供方决定。

历史窗口默认32768，历史高水位20000、裁剪目标12000，输出2048，并发2，超时60秒；这些均在API模型配置。工具上限默认8轮，在角色设置。达到高水位批量截断输入，不删除JSONL；当前字节保守估算，无精确tokenizer/费用预算。

固定工具为send_message、search_history、search_memory、read_document、update_document、finish。公开发言只能经send_message，可多条纯文本，不渲染Markdown/流式最终正文。历史最多50条、记忆最多50行；文档正文上限及权限见06-role-runtime。

请求不自动重试。一次没返回工具不能认定永久不支持：记录finishReason，对同API/模型暂缓60秒后允许新处理；输出耗尽提示调大额度，不提供文本工具协议降级。

缓存只作为可能的收益，不承诺供应商/模型/Key间共享，也不声称已采集完整命中率。历史稳定前缀优先，角色时间放后；新消息重建、删除、批量裁剪或Schema变化可能影响命中。

## 本地数据与维护

初始化仅由initialized.json控制，无标记按固定预设UUID补缺，已有标记不检查内容。ZIP默认不带Key，单角色不带聊天，冲突按UUID覆盖或均保留。归档/删除/清理范围见04-data。

目录边界自动检查；UI与功能保持当前行为。单群聊导出、加密、增量快照、细粒度状态、统一保存事务和长期后台可靠性未声称完成。真实浏览器和第三方工具协议仍需独立验收。
