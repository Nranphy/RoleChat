# 关键设计决定

当前方案默认和实现以16-final-architecture、04-data及17-modular-architecture为准；用户最新明确要求优先。本文件保留主要替代关系，已实施内容不再列为未来计划。

## 产品与数据

- 仅Web，无Matrix、登录、多真实用户或独立控制后端；Android暂不开发。
- 用户最初所说RealChat实际为RoleChat，唯一开发目录D:/Project/RoleChat。
- 角色身份文件改名为identity.md；灵魂和记忆为全小写soul.md、memory.md。
- 主存储采用OPFS独立文件，Key单独auth.json，主题偏好留浏览器偏好；无数据库选型待定项。
- ZIP支持完整包和无聊天的单角色包，默认不带Key；按UUID冲突选择覆盖或均保留，不按名字合并。
- 用户创建采用UUIDv4，预设固定UUIDv5，初始化只由initialized.json控制；有标记不补预设，无标记刷新按固定ID补缺。
- 角色/会话先归档，永久删除角色时选择保留私聊，群历史不受影响；消息删除不保留删除事件。
- 当前无旧正式数据，不做profiles旧格式、v2命名或迁移兼容。

## 角色运行

- 每条消息直接激活已取消，仅随机周期检查和行程切换；@影响检查概率但不唤醒概率0角色。
- 连续AI硬上限已替换为有下限的衰减；5%为系数下限。
- 未命中行程概率可按角色配置，默认50%；同角色跨会话串行，不同角色并发。
- 处理中有新消息时保留已执行过程，更新上下文后继续；不取消HTTP，不重置总请求预算。
- 按正文过滤重复消息已撤掉，仅按工具调用ID识别同一次操作；行程切换不为当前目标重复排队。
- 无工具返回不再永久停用模型；提示结束原因并暂缓60秒，后续允许新处理。
- 原生工具是前提，公开回复由send_message，无Markdown/流式；记忆关键词检索，不用embedding；文档无修订历史。

## 结构

目录已分为app、presentation、application、domain、infrastructure、core。旧PreviewStore改为AppStore，preview_models拆为领域模型，原UI展览及空目录移除。SDK、浏览器和检测适配在装配边界注入，通用激活通过策略接口扩展。

## 仍需验证或单独立项

不同供应商工具协议/CORS、后台冻结、配额及实际ZIP上传下载需实机验证。单群聊导出、Key加密、精确tokenizer、费用预算和可靠关闭后运行不属于当前已完成范围。保存事务、可变状态权限和快照写入成本属于后续技术改进；不阻碍当前目录规范化交付。
