# 界面与交互规范

当前实现位置为lib/presentation，组件边界见12-ui-component-structure.md。视觉参考的历史来源见11-fluffychat-ui-audit.md，用户指定的交互优先。

## 主题与页面

AppTheme统一浅色、深色和配色；明暗默认跟随系统，轻量偏好持久化。FormMetrics统一48px表单高度、6px操作间隔及104×40资料弹窗按钮，公共样式只在对应组件调整。

主导航只有聊天、角色、设置。角色与设置使用ContentPage统一内容宽度和外观，不另加大标题。宽屏并排显示会话与聊天，窄屏提供返回入口。列表选中/hover为单层背景，过渡较快，不叠加名称或摘要局部点击效果。

## 资料编辑

- 角色Tab固定顺序：基础、样例、身份、灵魂、记忆、行程。
- 群聊Tab固定顺序：基础、背景、成员；与角色使用同一ProfileDialogFrame和左对齐固定宽度导航。
- 基础页先选API，再选该API下已配置模型，保留真实检测按钮及成功/失败提示。模型参数集中在API编辑弹窗中。
- 身份/灵魂/记忆/背景使用DocumentEditorTab；说明行间距一致。灵魂和记忆可配置自主更新锁，行程规则可单独锁定。
- QA标签为user、assistant，空态“暂无样例”；行程空态“暂无行程”，结构化条件和时间控件高度一致。
- 名称显示在头像右侧，点击进入下划线编辑；已有资料名称提交后立即保存。头像悬停出现编辑区域，支持选择、方形裁剪并保存图像，不出现额外tooltip或上传按钮。
- 有图片时保持图片，不闪回占位。无图片时用名称首字及配色，角色资料、卡片、会话与消息保持一致；不使用emoji头像或装饰性标语。

## 聊天

Enter发送，Shift+Enter换行，Ctrl+Enter不承担发送。聊天打开后滚到底部；搜索与引用定位优先，不被初始滚动覆盖。用户上翻后不因普通重建强制回到底部。

同一发送者连续消息合并显示头像/名称。群聊名字采用与头像同色系、更深的颜色；时间在气泡外，气泡按实际换行自适应高度。引用展示“发言人: 内容”，名称保留颜色。

消息操作按钮仅在整行hover或菜单打开时显示；用户消息按钮在左，角色在右，对齐气泡底部，不随时间位置变化。搜索结果显示发送人并按时间倒序，搜索、气泡引用和输入区引用共用消息定位逻辑。

菜单外层圆角裁切，内边距为0，条目hover填满直角区域；优先锚定控件下方，空间不足时避让。不显示已读或免打扰。空会话仅显示居中的“暂无对话”。

## 验收

覆盖浅深主题、手机/桌面宽度、长名称、长文本、连续多气泡、空态、菜单边界、表单校验及异步检测关闭后返回。首选复用已有组件，不为单页重新实现相同样式。
