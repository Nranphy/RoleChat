# 产品与当前范围

RoleChat是面向角色扮演的单用户Flutter Web应用。用户可与角色私聊，也可建立多角色群聊；没有账号、登录、Matrix或多个真实用户聊天。当前不开发Android产物，不运行独立本地或云端控制后端。

## 已实现

- 聊天、角色、设置三个主入口及窄宽屏布局；无界面展览Tab。
- 多API配置，每个配置内可管理多个模型及其运行参数。角色从API/模型联动列表选择，不自由填写未配置的模型。
- 角色资料包括头像、名称、样例、identity.md、soul.md、memory.md、行程、时区和运行设置；不设角色简介。
- 新角色建立一个空私聊；群聊包含背景文档background.md和成员列表。
- 定期检查与行程切换驱动激活，角色并行，同角色跨会话串行。新消息不直接激活；100%基础概率也不要求模型必定发言。
- 模型通过原生工具发送消息、检索历史/记忆和更新允许的文档。公开消息为纯文本，无Markdown渲染或流式草稿。
- 业务数据以OPFS文件持久化，主题偏好存浏览器偏好。支持完整ZIP、无聊天记录的单角色ZIP、UUID冲突处理、归档和数据清理。
- 初始化标记缺失时按固定UUID补建五个预设角色、私聊和社团群聊；有标记时不检查或修复预设。用户可以删除预设。

## 配置与删除

API模型参数包括上下文、高低水位、输出额度、并发、超时和协议。角色运行设置包括检查间隔、默认激活概率及工具轮数；默认激活概率只在未命中行程时使用。

模型改名同步其角色引用，删除正在使用的模型前提示并清空对应选择。删除API前提示使用角色。角色和群聊先归档；永久删除角色可保留私聊，群聊历史不受影响；永久删除会话明确提示其历史和配置会删除。

## 边界

客户端直接访问用户配置的模型服务，服务需允许浏览器CORS。发送给模型的上下文会离开本地；本地存储不代表离线推理。浏览器冻结或关闭后无法保证调度，OPFS按站点隔离，不自动跨设备同步。

当前没有附件、语音、embedding、修订历史、任意文件/shell工具或后台服务。工具错误、保存失败和浏览器限制须如实提示；具体实现与验证边界见14-handoff.md。
